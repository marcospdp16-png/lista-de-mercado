# Lista de Mercado 1.0.0

Primeiro protótipo funcional do projeto pessoal Lista de Mercado.

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no navegador.

## Estado atual
- Dashboard responsivo
- Lista de produtos
- Pesquisa
- Marcar item como comprado
- Cálculo automático do total
- Modal para adicionar produto
- Menu responsivo para celular
